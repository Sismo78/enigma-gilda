# Ænigmå – sito della gilda

1. Carica questa cartella su un nuovo repository GitHub.
2. Su vercel.com: Add New > Project > scegli il repository.
3. In Environment Variables inserisci: BLIZZARD_CLIENT_ID, BLIZZARD_CLIENT_SECRET, BLIZZARD_REGION=eu, GUILD_SLUG=ænigmå
4. Premi Deploy.

Per aggiornare boss uccisi e traguardi modifica data/progressione.json (da GitHub, dal browser).
